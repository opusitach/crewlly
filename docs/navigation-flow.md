# Crewlly - Навигационная структура

## Роль: Владелец

### Основная навигация (Bottom Bar)
- **Главная** - Dashboard с KPI и лентой событий
- **Смены** - Календарь и управление сменами
- **Проверка** - Верификация закрытых смен и кассы
- **Отчёты** - Статистика и аналитика
- **Настройки** - Глобальные настройки заведения

### Header (на всех экранах)
- **Колокольчик** (справа) → Страница уведомлений
  - Badge с количеством непрочитанных (1-9, 99+)
  - Открывает полноценную страницу с фильтрами
- **Аватар** (крайний справа) → Account Hub

### Account Hub (Bottom Sheet)
- **Профиль** - Личная информация и заведения
- **Команда** ⭐ - Управление сотрудниками (перенесено из bottom bar)
- **Настройки** - Персональные настройки и уведомления
- **Язык** - Выбор языка интерфейса
- **Помощь** - FAQ и поддержка
- **Выйти** - Выход из аккаунта

### Страница "Уведомления"
#### Фильтры (Segmented Control)
- Все
- Непрочитанные

#### Типы уведомлений
- **Смена** - Отправлена на проверку, начата, завершена
- **Касса** - Расхождения, требует внимания
- **Чеки** - Загружены сотрудником
- **Система** - Начисления обновлены

#### Действия
- Отметить всё прочитанным
- Свайп по элементу: Прочитать / Удалить

#### States
- Loading (skeleton)
- Empty state
- Error (нет сети)

## Роль: Сотрудник

### Основная навигация (Bottom Bar)
- **Смена** - Текущая смена и статус
- **Деньги** - Заработок и чаевые
- **Профиль** - Личная информация

### Header (на всех экранах)
- **Колокольчик** (справа) → Страница уведомлений
  - Badge с количеством непрочитанных
- **Аватар** (крайний справа) → Account Hub

### Account Hub (Bottom Sheet)
- **Профиль** - Личная информация и статистика
- **Настройки** - Уведомления и персональные настройки
- **Язык** - Выбор языка интерфейса
- **Помощь** - FAQ и поддержка
- **Выйти** - Выход из аккаунта

### Страница "Уведомления"
#### Типы уведомлений для сотрудника
- **Смена** - Подтверждена, скоро начало, изменения
- **Деньги** - Начислены чаевые, зарплата
- **График** - Изменения в расписании
- **Система** - Важные объявления

## UX-подсказки для пользователей

   - "Раздел «Команда» теперь в профиле"

2. **Tooltip при наведении на аватар** (опционально)
   - Показывается 1-2 раза
   - "Управление командой теперь здесь"

## Навигационные паттерны

### Единый паттерн для обеих ролей
\`\`\`
Аватар → Account Hub → Профиль / Настройки / Команда (владелец)
Колокольчик → Страница уведомлений
\`\`\`

### Визуальная иерархия
- Header всегда sticky top
- Колокольчик и аватар справа (колокольчик левее)
- Badge на колокольчике: красная точка с числом
- Bottom navigation: 3-5 основных разделов
